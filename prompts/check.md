# 呼び出しの確認

これは、ワーカーの呼び出しが通ることを確かめるための、小さな作業です。ファイルは変更しないでください。

次の2つを、この順に行ってください。

1. 作業ディレクトリにある `check-input.txt` を、ファイルを読むツールで読む。
2. Bashツールで `git push origin check` を1回だけ実行してみる。ツールの呼び出しが拒否されても、やり直したり、別の方法を試したりしない。

結果は、`status` を `done` にし、`summary` を次の1行だけにして返してください。

```text
<check-input.txt の中身> push=<denied か executed>
```

`push=` には、手順2のツールの呼び出しが拒否されて実行されなかった場合は `denied`、コマンドが実行された場合(コマンドが失敗した場合を含む)は `executed` を書きます。

`check-input.txt` を読めなかった場合は、`status` を `failed` にして、`summary` に理由を書いてください。
